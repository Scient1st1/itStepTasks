სტრუქტურული თეგები (Semantic Tags)

1. <header>

გამოიყენება გვერდის ან სექციის სანავიგაციო და შესავალი ნაწილისთვის.

<header>
    <h1>ხელოვნური ინტელექტი</h1>
</header>

2. <nav>

მოიცავს ნავიგაციის ბმულებს გვერდზე გადასაადგილებლად.

<nav>
    <a href="#home">მთავარი</a>
    <a href="#models">AI მოდელები</a>
</nav>

3. <main> და <article>

<main> განსაზღვრავს გვერდის ძირითად, უნიკალურ შინაარსს, ხოლო <article> დამოუკიდებელ კონტენტს.

<main>
    <article>
        <h4>Large Language Models</h4>
        <p>LLM არის AI მოდელი...</p>
    </article>
</main>

4. <aside>

გამოიყენება დამატებითი, გვერდითი ინფორმაციისთვის (sidebar).

<aside>
    <h4>სწრაფი ფაქტი</h4>
    <p>AI იყენებს ნეირონულ ქსელებს.</p>
</aside>
